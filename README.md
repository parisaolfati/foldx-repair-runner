# FoldX PDB Repair Runner

A clean, portable Bash shell script to automate the execution of FoldX `RepairPDB` across multiple PDB structures.

## Usage

1. Place your FoldX executable path in the script configuration (`FOLDX_PATH`).
2. Put your raw PDB files inside the input directory (`INPUT_DIR`).
3. Run the script:
```bash
bash repair_pdbs.sh
```
